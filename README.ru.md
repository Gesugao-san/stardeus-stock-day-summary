# Сводка биржи (Stock Day Summary)

[English](README.md) | **Русский**

[![CI](https://github.com/Gesugao-san/stardeus-stock-day-summary/actions/workflows/ci.yml/badge.svg)](https://github.com/Gesugao-san/stardeus-stock-day-summary/actions/workflows/ci.yml)

Мод для [Stardeus](https://store.steampowered.com/app/1380910/Stardeus/) **v0.15** и **v0.14**: в конце каждого
биржевого дня показывает, сколько портфель заработал или потерял, и может поставить игру на паузу.

![обложка](ModCover.jpg)

## Возможности

- Уведомление (в v0.14 — событие в списке **«События»**), например `Биржа за день: +$3.12K (+4.64%)`,
  зелёное или красное.
- По клику открываются подробности: итог дня, стоимость портфеля, прибыль, зафиксированная
  продажами, нереализованная прибыль, разбивка по активам и номера сравниваемых дней графика.
- Та же строка в журнале событий.
- Пауза при появлении сводки (по желанию).
- Автосохранение прямо перед закрытием дня (по желанию): штатное автосохранение игры за 10 игровых
  минут до границы дня, пока цены ещё старые. Раз в игровой день оно занимает слот в ротации
  автосохранений игры.
- Каждая продажа и цены каждого дня пишутся в `Player.log` (строки начинаются с
  `[StockDaySummary]`), так что любую цифру можно перепроверить.

## Как считается

Цены в Stardeus меняются раз в биржевой день, на его границе. Итог дня сравнивает цену, которая
держалась весь закрытый день, с новой ценой:

```
итог дня = (стоимость по новым ценам + выручка от продаж за день)
         − (стоимость по старым ценам + стоимость покупок за день)
```

Акции, купленные в течение дня, считаются от цены покупки, проданные — по цене продажи. Старые цены
берутся из собственной истории цен игры, поэтому сводка верна сразу после загрузки сохранения.
Мод не знает только о продажах, сделанных *до* загрузки.

## Настройки

- **v0.15:** Настройки → **Сводка биржи**, вкладка в окне настроек самой игры (из главного меню и из
  меню паузы).
- **v0.14:** Главное меню → **Mod Settings** → Stock Day Summary. Если установлен
  [Modding Overhauled](https://steamcommunity.com/sharedfiles/filedetails/?id=3566425397), страница
  появляется в его меню *Mod Settings*, иначе мод сам добавляет кнопку «Настройки модов».

| Опция | По умолчанию |
|---|---|
| Пауза при сводке биржи | вкл. |
| Сразу открывать окно подробностей | выкл. |
| Сводка без акций | выкл. |
| Автосохранение перед закрытием дня | выкл. |

Настройки хранятся в общем файле игры `Settings.txt`.

## Установка

- **[Мастерская Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3829155679):** подписаться и включить мод в главном меню → «Моды».
- **Вручную:** положить папку мода в
  `%USERPROFILE%\AppData\LocalLow\Kodo Linija\Stardeus\Mods\StockDaySummary`
  (нужны `ModInfo.json`, `ModCover.jpg`, `Translations\` и `0.15\Libraries\StockDaySummary.dll`
  и/или `0.14\Libraries\StockDaySummary.dll`) и включить его в главном меню → «Моды».

Мод ничего не пишет в сохранения, поэтому его можно добавить в текущую игру и убрать в любой момент.

Игра ищет `Libraries` сначала в папке со своей версией (`0.15\`, потом `0.14\`, …, потом корень мода),
поэтому одна папка мода работает в обеих версиях.

## Сборка

Нужны [.NET SDK](https://dotnet.microsoft.com/download) и установленная Stardeus: сборка ссылается
на `Stardeus_Data/Managed/*.dll` и поэтому идёт под ту версию игры, что установлена сейчас.

```cmd
build.cmd                          :: v0.15
build.cmd 0.14                     :: v0.14 (сначала переключите Stardeus в Steam на ветку v0_14_x)
build.cmd 0.15 "D:\Games\Stardeus"  :: если игра не в папке Steam по умолчанию
```

DLL появится в `0.15\Libraries\` или `0.14\Libraries\`. Коммитьте её вместе с изменением кода:
CI собрать её не может, поэтому в релизы идут DLL из репозитория.

Тесты расчёта прибыли и убытка запускаются без игры:

```cmd
dotnet run --project Tests
```

При каждом пуше GitHub Actions запускает эти тесты и `.github/scripts/check_mod.py`: строгий `ModInfo.json`,
одинаковые ключи и плейсхолдеры `{0}` во всех переводах, перевод каждого ключа из кода, полноту папок
под каждую версию игры, размер обложки и то, что каждая DLL в репозитории собрана под свою версию игры
и с версией из `ModInfo.json`.
Сама DLL мода собирается только локально: для неё нужны DLL игры.

### Релиз

1. Поднять `ModVersion` в `ModInfo.json` и версию в `Code/Shared/AssemblyInfo.cs`.
2. Добавить раздел `## <версия>` в [CHANGELOG.md](CHANGELOG.md): он станет описанием релиза.
3. Пересобрать обе DLL (`build.cmd 0.15`, `build.cmd 0.14`) и закоммитить их.
4. Actions → **Release** → *Run workflow* или пуш тега `v<версия>`.

Workflow прогоняет проверки и тесты, собирает `StockDaySummary-<версия>.zip` (папка мода, готовая к
распаковке в `Mods`) и создаёт черновик релиза; опубликовать его нужно на странице Releases.

### Структура

| Путь | Что там |
|---|---|
| `Code/Shared/` | Код для обеих версий игры |
| `Code/Shared/Core/DayPnlCalculator.cs` | Чистая математика прибыли и убытка, без игровых типов |
| `Code/Shared/StockDaySummarySys.cs` | Игровая система: ловит смену биржевого дня, собирает сводку |
| `Code/Shared/SummaryPresenter.cs`, `SummaryText.cs` | Тексты, строка журнала, окно подробностей, пауза |
| `Code/Shared/PreCloseAutosave.cs` | Автосохранение перед закрытием дня |
| `Code/Shared/Market/` | Чтение истории цен, учёт продаж (Harmony-патч на `MarketPortfolio.Sell`) |
| `Code/V015/` | Интерфейс v0.15: уведомление, вкладка настроек, регистрация через `[SelfInit]` |
| `Code/V014/` | Интерфейс v0.14: событие в «Событиях», страница *Mod Settings* и встройка в меню |
| `Translations/` | Английский и русский тексты |
| `0.15/`, `0.14/` | Собранные DLL, по одной на версию игры |
| `CHANGELOG.md` | Изменения по версиям; отсюда берётся описание релиза |
| `Artwork/make_cover.py` | Рисует `ModCover.jpg` |

Перед загрузкой в мастерскую игра отклоняет моды с файлами и папками на точку (`.git`,
`.gitignore`, `.vscode`), поэтому загружать нужно из чистой копии папки мода.
